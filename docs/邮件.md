# 邮件（第 1 阶段）

全部只读：IMAP 用 EXAMINE 打开文件夹、信头和附件都用 BODY.PEEK 取（服务器不会把信标成已读），不删、不移动、不发信。
密码只在这台电脑的保管处（credentials.py，`mail.<地址>`），设置里只有地址 / 服务器 / 端口 / 门店。
信头读过的记在 `cache/mail/<邮箱>.json`（按 UID；UIDVALIDITY 变了重读；老缓存没有附件段号 parts 的也重读）。

| 功能 | 在哪 | 代码 |
|---|---|---|
| 邮件摸底 | 系统设置 → 邮箱 → 邮件摸底… | `mail_client.survey`、`mail_page.run_survey` |
| 邮件核对（订单跟踪按邮件更新） | 采购订单跟踪「✉ 邮件核对」 | `mail_match`、`mail_track_dialog`，见 订单跟踪设计.md「邮件核对」 |
| 邮件里的批发商报价 | DETERSIVO采购「供应商报价」区「✉ 邮件 / ✉ 新报价 n」 | `mail_prices`、`mail_price_dialog`、`commands.mail_price_lists / mail_import_prices / mail_undo_prices` |

## 程序发订单邮件（2026-11-07）

订单跟踪里状态「✉ 待登记」点一下（或右键「✉ 发送订单…」）→ 发送窗口 → 审核 → 「✉ 发送」（先确认）→ 这几张单变「已下单」（下单日期 = 今天，单上记 `sent` 和这封信）。

- **一起发**：同一个订单文件的单（总仓采购一家供应商一个文件，几家店 + BMS）一封信发（`mail_send.group_of`）。
- **发件**（照现在的习惯）：一家店的单从这家店的邮箱发（邮箱设置里的「门店」），BMS / 几家店 / S.Concordio 从 INFO@BMSPSRL.COM（`sender_for`）。
- **主题**：`Ordine 供应商 Foiano|Capannori|S.Filippo|S.Marco|S.Concordio|BMS ddmm`，几家店 `Ordine 供应商 nPDV ddmm`；附件改名和主题一样。
- **收件**：先看共享通讯录 `Tracking ordini (programma)\supplier_contacts.json`（发过一次就存），没有就从各邮箱「已发送」里以前发给这家的订单信学（`recipients`）；收到的信里写的地址一律不用。抄送 = 一半以上订单信都有的公司同事（`usual_cc`）。
- **正文**：上次发给这家的那封订单信的正文（只读地读一下，去掉引用的旧信，主题里的旧日期换成新的），没有就用默认意大利文模板。
- **发送**：SMTP SSL 465（smtp.qiye.aliyun.com，老地址 smtp.mxhichina.com），发完 IMAP APPEND 到「已发送」（失败不影响，信已经发出）。审计记 `send_order`。
- 发过的单默认不再发（窗口会警告，确认后才重发）；订单文件只在生成它的电脑上，别的电脑上不让发。
- 手动「已确认 / 已到货 / 部分到货 / 卡住」从订单表右键菜单拿掉了，只在订单窗口（双击）里改；以后靠邮件核对自动更新。
- **安全**：用程序发信前，把各邮箱的密码换成阿里邮箱的「安全密码」（能单独作废，泄露也只能收发信）。
