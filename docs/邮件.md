# 邮件（第 1 阶段）

全部只读：IMAP 用 EXAMINE 打开文件夹、信头和附件都用 BODY.PEEK 取（服务器不会把信标成已读），不删、不移动、不发信。
密码只在这台电脑的保管处（credentials.py，`mail.<地址>`），设置里只有地址 / 服务器 / 端口 / 门店。
信头读过的记在 `cache/mail/<邮箱>.json`（按 UID；UIDVALIDITY 变了重读；老缓存没有附件段号 parts 的也重读）。

| 功能 | 在哪 | 代码 |
|---|---|---|
| 邮件摸底 | 系统设置 → 邮箱 → 邮件摸底… | `mail_client.survey`、`mail_page.run_survey` |
| 邮件核对（订单跟踪按邮件更新） | 采购订单跟踪「✉ 邮件核对」 | `mail_match`、`mail_track_dialog`，见 订单跟踪设计.md「邮件核对」 |
| 邮件里的批发商报价 | DETERSIVO采购「供应商报价」区「✉ 邮件 / ✉ 新报价 n」 | `mail_prices`、`mail_price_dialog`、`commands.mail_price_lists / mail_import_prices / mail_undo_prices` |

## 程序发订单邮件（2026-11-07）

订单跟踪里状态「✉ 待登记」点一下（或右键「✉ 发送订单…」）→ 发送窗口 → 审核 → 「✉ 发送」（先确认）→ 这几张单变「已下单」（下单日期 = 今天，单上记 `sent` 和这封信）。

- **一起发**：同一个订单文件的单（总仓采购一家供应商一个文件，几家店 + BMS）一封信发（`mail_send.group_of`）。
- **发件**（照现在的习惯）：一家店的单从这家店的邮箱发（邮箱设置里的「门店」），BMS / 几家店 / S.Concordio 从 INFO@BMSPSRL.COM（`sender_for`）。
- **主题**：`Ordine 供应商 Foiano|Capannori|S.Filippo|S.Marco|S.Concordio|BMS ddmm`，几家店 `Ordine 供应商 nPDV ddmm`；附件改名和主题一样。
- **收件**：先看共享通讯录 `Tracking ordini (programma)\supplier_contacts.json`（发过一次就存），没有就从各邮箱「已发送」里以前发给这家的订单信学（`recipients`）；收到的信里写的地址一律不用。抄送 = 一半以上订单信都有的公司同事（`usual_cc`）。
- **正文**（2026-11-26 起）：固定意大利文模板（`mail_send.compose`），段落照同事平时手写的信：缺货 / 停产 / 改价 / 改 EAN 请告知、两天内回 XLSX 确认（写预计到货日）、回信保留主题、DDT 写订单号、没有预约一律拒收 + 预约网址。程序只填 订单号 · 供应商 · 门店抬头 / 地址 / 卸货电话 · 箱数。
- **主题**：照同事习惯「Ordine SAIS Foiano 2611 · n. FO-2611-3F9A」（几家店一起写 nPDV，用 BMS 那张的号）。
- **称呼**：「Ciao 名字,」只从**上次发给同一个收件地址**的订单信开头取（一家供应商好几个人时不会叫错人），取不到写「Buongiorno,」。
- **发件邮箱**：「订单发件邮箱」没填的门店用平时的（`DEFAULT_SENDERS`：1 info@ · 2 infolucca@ · 3 info.s.filippo@ · 4 info.s.marco@ · 5 info.s.concordio@ · BMS info@bmspsrl.com，要在邮箱设置里）。凑到 BMS 的单一律 BMS 邮箱；BMS 地址 / 卸货电话和三号店一样，只靠抬头 BMS PARTNERS SRL 区分。
- DETERSIVO 的信不变（`compose_deter`）。
- **发送**：SMTP SSL 465（smtp.qiye.aliyun.com，老地址 smtp.mxhichina.com），发完 IMAP APPEND 到「已发送」（失败不影响，信已经发出）。审计记 `send_order`。
- 发过的单默认不再发（窗口会警告，确认后才重发）；订单文件只在生成它的电脑上，别的电脑上不让发。
- 手动「已确认 / 已到货 / 部分到货 / 卡住」从订单表右键菜单拿掉了，只在订单窗口（双击）里改；以后靠邮件核对自动更新。
- **安全**：用程序发信前，把各邮箱的密码换成阿里邮箱的「安全密码」（能单独作废，泄露也只能收发信）。

## 订单窗口里看邮件（2026-11-08）

不做完整的邮件软件（Foxmail 照用）；和订单有关的邮件放进订单里看。订单跟踪双击一张单 → 窗口多一个「邮件（n）」标签页（`order_mail_tab.OrderMailTab`）：

- 列表：这张单的邮件 = 单上记的事件（邮件核对 / 程序发信时记的，`mails`）+ 程序发的那封（`sent.mid`）+ 回这几封的信（In-Reply-To，两层）。同一封信（Message-ID 一样）只留一份（`mail_match.related`，读本机缓存 cache/mail/，不连网）。事件现在都记 Message-ID（`id`），老事件按 主题 + 发件人 + 时间 找。
- 点一封：发件人 → 收件人 · 日期 · 哪个邮箱；附件按钮（下载到 cache/mail_att/ 再打开，`commands.mail_attachment`）；正文纯文字（`commands.mail_view_body`，最多 3 万字，存 cache/mail_bodies.json 的 `view|` 键）。都是只读（EXAMINE + BODY.PEEK），Foxmail 里不会变成已读。
- 回信还是用 Foxmail：「复制主题」方便在 Foxmail 里搜。

## 订单邮件一一关联（2026-11-25）

用户：「订单一定要一一关联上，不然我们后续全都没法做」。

- **发**：除了 DETERSIVO，订单信一律用这家店自己的邮箱发（「订单发件邮箱」设置里的六个，`mail_send.sender_for`），
  一张单一封信；BMS 的单用 BMS 邮箱。DETERSIVO 照旧一家批发商一封、BMS 邮箱。
- **收**（邮件核对，`mail_match.analyze`）：供应商的确认 / 发货 / DDT 信对哪张单，按可信度：
  ① 以前已经关联过（单上 mails 记了这封信的 Message-ID）；② 我们的订单号；③ 回复我们的订单信（In-Reply-To）；
  ④ **收货抬头和地址**（`mail_link.store_of`）：正文 + 附件（PDF 前 4 页 / Excel 前 80 行 / Word / 文本，
  `mail_client.fetch_texts` 只读）里 CASA & TE 哪家公司（抬头 3 分）、街道 + 门牌（3 分）、邮编、城市，
  先看「Destinazione / Consegna / Luogo…」那几行（DDT 上开票的公司和送货的门店常常不一样），再看全文；
  最高分 ≥ 3 且比第二名多 1.5 才算。BMS 和 S.FILIPPO 同一个地址（Via di Tiglio 1893），只能靠抬头分；
  ⑤ 主题 / 附件名里的门店名；⑥ 哪个门店邮箱收到的（门店自己的订单邮箱）。
- **一封信只对一张单**：对不上、或者好几张都可能的，不给建议，进窗口第二页「待处理邮件」
  （左边信，右边可能的单 + 信的正文和附件文字），人选一张点「关联到这张单」（先确认、可撤销）→ 单上记住这封信，
  以后这封信只算这张单（`mail_match.link_suggestions`，状态不用改的只记信 field link）。
- 正文 + 附件文字缓存在 cache/mail_bodies.json（{"b": 正文, "a": 附件文字}，最多 2000 封）。
- PDF 用 pypdf 4.3.1（纯 Python、BSD，**放在程序文件夹 pypdf/**，spec / requirements 加了）。
- 地址按「订单发件邮箱」窗口里每家店的送货抬头 / 地址（`mail_send.profile`），那里要填准确。
