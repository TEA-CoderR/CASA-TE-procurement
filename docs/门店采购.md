# 门店采购（LUCAS定制采购 → 门店采购，2026-11-03）

门店自己采购的供应商汇总在共享盘 `D:\SynologyDrive\SynologyDrive\2 Griglia per gli ordini\03 Griglia per gli ordini PDV`，
按星期分 `01 LUNEDI … 05 VENERDI`，每家供应商一个 SCHEDA。同一家供应商有时候总仓采购、有时候门店自己采购（例如 IDRO-BRIC 两边都有），
两边各管各的。

## 和总仓采购的不同

| | 总仓采购（Centrale Acquisti） | 门店采购（PDV） |
|---|---|---|
| SCHEDA | GRIGLIA PER TUTTI PDV + 每家店一页 | 一页 GRIGLIA（SAIS 这种分好几页：BAZZAR & DRUG / ESTIVI / INVERNO，几页一起读） |
| 起订量 | 够了直送，不够并 BMS | **每家店各自达到起订量**（用户 2026-11-03 定），差一点凑单（凑单范围和总仓采购共用），不够这次不订；没有 BMS、没有门店间调货 |
| 订单文件 | 一家供应商一个文件 | **一家供应商 × 一家店一个文件** `Ordine_供应商_门店_日月.xlsx` |
| 订单跟踪 | 来源「总仓采购」 | 来源「门店采购」（store_pdv），两边的待登记互不影响 |

## 订单文件里自动填的

复制原 SCHEDA（图片、格式保留），GRIGLIA 页：
- `Colli`：箱数（不订的行清空）
- `Fatturazione`（F1）：开票抬头。「Dati Filiale 2」页 = 每家店自己开票，取这家店那一行 A 列；「Dati Filiali 1」页 A 列只有一行 = 发票都开给 BMS
- `Luogo di destinazione`（F2）：这家店的送货地址（Dati Filiali 页 B 列）
- `NUMERO ORDINE`（H1）：日月年-门店简写-01（FO / MA / SF / SM / SC，`store_orders.STORE_ABBR`）
- `Data Ordine`（H2）：今天
- `Data Consegna Entro` 不动

门店按每行第一行的公司名认（`_store_of_text`）：用户的文件里 S.CONCORDIO 的 PEC 写成了 casaete.smarco@pec.it。

## 代码
- `store_orders.parse_scheda`：没有门店页、有 GRIGLIA 页 → `info["pdv"]`（`read_pdv_header`），`sheets` 五家店都指向第一页 GRIGLIA；
  几页 GRIGLIA 时第 k 页的行号 + k × `PDV_ROW_BLOCK`
- `plan_supplier(mode="pdv")`（`scheda["pdv"]` 时 allocate 自动用）、`write_plans` → `write_pdv_file`
- `store_orders.day_dirs`：「周一」或「01 LUNEDI」都认
- `store_order_page.PdvOrderPage`：设置存 settings["store_pdv"]，订货明细的列第一次照抄总仓采购的
- 门店报告里的「Disp. fornitore diretto」：总仓采购 + 门店采购两个文件夹的 SCHEDA 都算（`scheda_index` 可以给几个文件夹）
