# 门店申请（2026-11-27）

门店在扫码枪上扫到订不了的商品，不再打电话问办公室，直接在扫码枪上申请；办公室在程序「Griglia → 门店申请」回复，门店扫码枪上马上看得到。

## 哪些商品能申请（用户定）
- 查不到的商品（SCONOSCIUTO）
- Griglia 已停用的商品（TOLTO DALLA GRIGLIA）
- 批发商都没货的商品（NON DISPONIBILE）
- 非 Griglia 商品（NON IN GRIGLIA）不在里面：照旧写原因直接加进清单。

## 门店（扫码枪）
商品卡片底部主按钮「Chiedi all'ufficio」→ 底部窗口：
- 为什么要：I clienti lo chiedono / Sostituisce un articolo finito / Novità del fornitore / Altro（要写一句）；
- 想订几箱（0 = 只问一下）；
- 备注；
- 照片（可选，用扫码枪的相机）。

同一家店同一个条码只有一张没处理的申请，再申请就是改那一张。扫码枪上有单独一页「Richieste all'ufficio」（首页一行进去，写着几条回复没看、几条在等；Da fare 里只放要看的 + 「Tutte le richieste」）：分 Da guardare（没看的回复、办公室要补充的）/ In attesa / Risposte / Tutte，一个商品一行（状态、办公室的回复或当时问的、日期），点一行打开商品卡片看完整回复（看了算已读）。近 90 天、全店几台扫码枪的都在。再扫这个商品，卡片上也直接显示办公室的回复。

## 办公室（程序）
每个条码一行，几家店问的合在一起。右边先列出程序查到的：
- 数据库里有没有、每家店 30 天销量；
- 这周哪家批发商有、价格；
- 直厂；
- Griglia 里最像的商品（找替代商品同一套相似度算法），并给出建议。

| 回复 | 门店看到 | 程序顺带做的事 |
|---|---|---|
| 换成别的商品 | Ordina al suo posto: … | 以后扫这个条码显示 SOSTITUITO → 该订的那个（扫码枪目录 aliases） |
| 加进 Griglia | Aggiunto in Griglia… | 先开「新增商品」窗口（数据库预填、过检查），存进程序里的 Griglia；扫码枪目录把它算 Griglia 商品 |
| 只订这一次 | Ok, lo ordiniamo questa settimana | — |
| 向直厂订 | Si ordina dal fornitore diretto X | — |
| 不做这个商品 | Non lo trattiamo: 原因 | — |
| 要更多信息 | 问的那句 | 门店补一句 / 补照片后回到待回复 |

- 「换成别的商品」「加进 Griglia」「只订这一次」可以把门店要的箱数直接放进这家店这周的扫码枪清单。
- 合理性检查（`product_requests.box_check`）：
  - ≥ 20 箱或金额 ≥ €1,000 不让放；
  - ≥ 6 箱或金额 ≥ €300 黄字提醒。
- 回复前先确认，做完右下角有「撤销」：撤销后回复去掉，清单箱数改回原来的。加进 Griglia 的商品要在「Griglia 改动记录」里撤销。
- 超过 2 个工作日没回复变红。图标栏 Griglia 上的数字是待回复的个数（10 分钟查一次）。
- DETERSIVO 第 1 步「准备好了吗」也会提醒。

## 预约平台
- 表 `product_request`（迁移 0008）。
- 扫码枪接口：
  - `POST /api/scanner/requests`；
  - `POST /api/scanner/requests/:id`，action = reply / seen / cancel；
  - 申请随 `/api/scanner/list` 一起下发（requests）。
- 采购系统接口：
  - `GET /api/erp/requests?status=&days=`；
  - `POST /api/erp/requests/:id`，action = answer / reopen；
  - `GET /api/erp/requests/:id/photo`。
