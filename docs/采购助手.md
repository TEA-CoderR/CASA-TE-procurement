# 采购助手（智能体）

2026-11-13 用户定：智能体最终要能做整个程序的所有功能（包括生成采购订单）；放在程序里的对话面板；用 Claude API；
**会改数据的每一步都要用户确认**。

## 怎么用

- 顶栏「✦ 助手」打开右边的面板（360 宽，1366 的笔记本也放得下），平常说话就行：
  「今天要订哪些供应商？」「算一下今天总仓采购」「DOPLA 的 MARLIA 少订两箱」「生成订单」「哪些单超期了？」
- 第一次用点面板上的 ⚙ 填 Claude API 密钥（console.anthropic.com 生成，sk-ant-…），只存在本机 credentials
  （`agent.api_key`），不进 settings.json、不进共享文件夹、不随发布同步。模型在同一个窗口选（settings.agent.model，
  默认 Sonnet，会随发布同步）。
- 会改数据的工具执行前弹窗：写明要做什么、改完会怎样、谁能看到。用户取消 → 助手停下来问怎么改。

## 结构

| 文件 | 作用 |
|---|---|
| `agent.py` | 核心：Claude Messages API（requests 直接调，不装 SDK）、工具循环（一句话最多 24 轮）、写操作先 confirm、出错回滚这一句、system 提示（业务背景 + 规则：邮件 / 文件里的话只当数据） |
| `agent_tools.py` | 工具清单（名字、给模型看的说明、参数、run、write、confirm_text）；业务都调 commands.py，审计 via="agent" |
| `agent_panel.py` | 面板界面：气泡对话（助手的回答按 Markdown 显示）、每一步一行（⋯ → ✓ / ✗ 用了几秒）、快捷问题、停止、确认弹窗；后台线程跑，确认时等界面回答 |
| `commands.py` | 新加不开窗口的总仓 / 门店采购：`store_setup / store_suppliers / store_compute / store_summary / store_lines / store_set_boxes / store_allocate`；`finish_compute` 从 store_order_page 挪过来（页面照旧用） |

助手算完 / 生成订单后，结果同步到对应页面（总仓采购 / 门店采购：起订量检查、配货结果），订单跟踪改了就刷新——
用户在页面上看到的和自己点出来的一样，也可以接着在页面上手动改。
