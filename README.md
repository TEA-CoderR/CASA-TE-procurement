# CASA&TE采购系统 v3

意大利门店采购与分货系统（PySide6 桌面程序）。v3 起统一成一个主程序，企业风格界面（浅色 / 深色），中 / 英 / 意三语。

> **接手开发请先看 [交接文档](交接文档.md)**；业务规则见 `docs/`。

## 模块

| 区域 | 页面 | 说明 |
|---|---|---|
| 概览 | 工作台 | 今天要下单的供应商、配货金额、最近比价、数据库状态 |
| 采购管理 | 门店配货 | 读 SCHEDA → 按新算法（服务水平法）算各店建议箱数 → 起订量检查（绿 = 单独够直送，橙 = 合起来够 BMS，灰 = 不够）→ 配货、凑单、BMS 合并 / 借货 → 生成订单（每次一个 `第NN次_HHMM` 文件夹） |
| | 批发商比价 | 原 v2.5 订单处理：扣减 eliminare、按最低价选供应商、起订量凑单、写回报价文件；可先检查门店订货清单 |
| | 比价结果 / 历史记录 / 起订规则 / 缺失查找 | |
| 分货管理 | 分货数据处理 | 补齐 EAN（codbarre）、Sheet1 双表格提取门店数量、一体化导出 |
| | 导入 / 导出 | 商品清单 → 各店销量 + 库存 → 调货判断 → 导出报告 |
| 系统 | 系统设置 / 运行日志 | 数据库、订货算法、文件位置、自动更新 |

## 运行 / 打包 / 发布

- 运行源码：`python main.py`
- 打包：双击 `build.bat`（输出 `dist\Procurement\CASA&TE采购系统.exe`，保留 settings / history）
- 发布更新给同事：双击 `publish_update.bat`（见 [自动更新说明](自动更新说明.md)）
- 测试：`python -m pytest -q`

## 安全

- 程序只读数据库，默认使用只读账号；密码不以明文出现在代码里（`secure_store.py`：本机输入的密码用 Windows DPAPI 加密保存）
- `settings.json`、`history/`、`publish_config.json`、`update_config.json` 不上传（见 `.gitignore`）
- 本仓库必须保持**私有**

## 功能概述

1. **读取采购订单** — 从 `ORDINE` 文件夹读取主订单文件
2. **扣减已处理数量** — 根据 `eliminare` 文件夹中的文件逐行扣减 COLLI 数量，数量为 0 的行自动删除
3. **构建价格矩阵** — 从 `distribuire` 文件夹读取各供应商报价，构建价格对比矩阵
4. **EAN 出现次数统计** — 统计每个 EAN 在多少个供应商报价文件中出现（写入 AB 列）
5. **选择最优供应商** — 按最低价格自动选择供应商；起订量（箱数/金额）不达标时自动凑单，总采购成本最低（DP + MILP）
6. **人工决定 / 手动调整** — 凑单比放弃更贵或超过设定线时弹窗让操作员决定；分配完成后可随时「修改分配…」
7. **回写订单** — 将分配结果写回各供应商文件

## 文件夹结构

```
总文件夹/
├── ORDINE/
│   └── 采购订单.xlsx          # 主订单文件
├── eliminare/
│   └── 已处理文件.xls/xlsx    # 需要扣减的文件
└── distribuire/
    └── 供应商报价.xls/xlsx    # 供应商报价文件
```

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 运行

```bash
python main.py
```

### 3. 使用

1. 点击「选择文件夹」，选择包含 `ORDINE`、`eliminare`、`distribuire` 三个子文件夹的总文件夹
2. 点击「开始处理」
3. 等待处理完成，查看日志输出

## Excel 文件格式要求

### 主订单文件（ORDINE）
| CODICE EAN | COLLI | ... |
|-----------|-------|-----|
| 123456    | 100   | ... |

### 扣减文件（eliminare）
| EAN | ... | COLLI | ... |
|-----|-----|-------|-----|
| 123456 | ... | 30 | ... |

### 供应商文件（distribuire）
| CODICE EAN | ... | PREZZO NETTO | ... | ORDINE | ... |
|-----------|-----|-------------|-----|--------|-----|
| 123456 | ... | €12.50 | ... | | ... |

## 日志

日志文件保存在 `logs/procurement.log`，包含每次处理的详细记录。

## 技术栈

- **Python 3.8+**
- **openpyxl** — Excel .xlsx 文件处理
- **pywin32** — .xls 格式转换（通过 Excel COM）
- **PySide6** — GUI 界面（浅色/深色主题，中文 / English / Italiano）
- **numpy / scipy** — 起订量凑单优化

## 配置

编辑 `config.py` 可修改：
- 文件夹名称常量
- Excel 列名常量
- 列位置常量
- 性能参数（最大行数等）
- 日志配置
