# 采购系统 v2.5

意大利门店采购订单自动化处理系统。

## 📚 文档

- [架构设计文档](ARCHITECTURE.md) - 系统架构、技术选型、演进路线图
- [架构决策记录](ADR.md) - ADR列表、决策背景和理由

## 功能概述

1. **读取采购订单** — 从 `ORDINE` 文件夹读取主订单文件
2. **扣减已处理数量** — 根据 `eliminare` 文件夹中的文件逐行扣减 COLLI 数量，数量为 0 的行自动删除
3. **构建价格矩阵** — 从 `distribuire` 文件夹读取各供应商报价，构建价格对比矩阵
4. **EAN 出现次数统计** — 统计每个 EAN 在多少个供应商报价文件中出现（写入 AB 列）
5. **选择最优供应商** — 按最低价格自动选择供应商；起订量（箱数/金额）不达标时自动凑单，总采购成本最低（DP + MILP）
6. **人工决定 / 手动调整** — 凑单比放弃更贵或超过设定线时弹窗让操作员决定；分配完成后可随时「修改分配…」
7. **回写订单** — 将分配结果写回各供应商文件

## 文件夹结构

```
总文件夹/
├── ORDINE/
│   └── 采购订单.xlsx          # 主订单文件
├── eliminare/
│   └── 已处理文件.xls/xlsx    # 需要扣减的文件
└── distribuire/
    └── 供应商报价.xls/xlsx    # 供应商报价文件
```

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 运行

```bash
python main.py
```

### 3. 使用

1. 点击「选择文件夹」，选择包含 `ORDINE`、`eliminare`、`distribuire` 三个子文件夹的总文件夹
2. 点击「开始处理」
3. 等待处理完成，查看日志输出

## Excel 文件格式要求

### 主订单文件（ORDINE）
| CODICE EAN | COLLI | ... |
|-----------|-------|-----|
| 123456    | 100   | ... |

### 扣减文件（eliminare）
| EAN | ... | COLLI | ... |
|-----|-----|-------|-----|
| 123456 | ... | 30 | ... |

### 供应商文件（distribuire）
| CODICE EAN | ... | PREZZO NETTO | ... | ORDINE | ... |
|-----------|-----|-------------|-----|--------|-----|
| 123456 | ... | €12.50 | ... | | ... |

## 日志

日志文件保存在 `logs/procurement.log`，包含每次处理的详细记录。

## 技术栈

- **Python 3.8+**
- **openpyxl** — Excel .xlsx 文件处理
- **pywin32** — .xls 格式转换（通过 Excel COM）
- **PySide6** — GUI 界面（浅色/深色主题，中文 / English / Italiano）
- **numpy / scipy** — 起订量凑单优化

## 配置

编辑 `config.py` 可修改：
- 文件夹名称常量
- Excel 列名常量
- 列位置常量
- 性能参数（最大行数等）
- 日志配置

## 打包

Windows 下双击 `build.bat`，生成的 exe 在 `dist/`。
